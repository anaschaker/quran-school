# دليل المدير — مدرسة القرآن الكريم

هذا الدليل موجَّه لمدير المدرسة (غير التقني). كل خطوة مصوّرة بالنص.

## 1. تسجيل الدخول

1. افتح موقع المدرسة في المتصفح.
2. اضغط «تسجيل الدخول» في الأعلى.
3. أدخل البريد (أو رقم الهاتف) وكلمة المرور.
4. ستنتقل تلقائيًا إلى «لوحة الإدارة».

> إن طُلب منك «تغيير كلمة المرور» فغيّرها قبل المتابعة.

## 2. إضافة معلم

1. من القائمة الجانبية: «المعلمون» → «إضافة معلم».
2. املأ: الاسم، البريد (فريد)، الهاتف، كلمة المرور المؤقتة.
3. اضغط «حفظ». المعلم يظهر في الجدول.
4. أرسل للمعلم بريده وكلمة المرور المؤقتة؛ سيُطلب منه تغييرها عند أول دخول.

## 3. إضافة حلقة

1. «الحلقات» → «إضافة حلقة».
2. الاسم، المعلم (من القائمة)، الأيام، الوقت، الحد الأقصى للطلاب.
3. «حفظ». تظهر في الجدول (مع جدول أسبوعي).

## 4. إضافة طالب

1. «الطلاب» → «إضافة طالب».
2. الاسم، تاريخ الميلاد، المرحلة، ولي الأمر (إن وُجد)، ملاحظات.
3. «حفظ». الطالب يُضاف للحساب (إن كان لولي أمر) و可以 إضافته لحلقة من صفحة الحلقة.

## 5. إضافة طالب إلى حلقة

1. «الحلقات» → افتح الحلقة.
2. في قسم «الطلاب» اختر طالبًا من القائمة واضغط «إضافة».
3. لا يمكن تجاوز «الحد الأقصى».

## 6. قبول طلبات التسجيل (من public /register)

1. «طلبات التسجيل» (في القائمة).
2. راجع البيانات (اسم الطالب، ولي الأمر، phone، مرحلة).
3. اضغط «قبول» → يُنشأ حساب ولي الأمر + الطالب بكلمة مرور مؤقتة (تُعرض لك مرة واحدة).
4. أرسل كلمة المرور لولي الأمر.
5. «رفض» عند عدم الملاءمة.

## 7. الرسوم

- **خطط الرسوم**: «الرسوم» → «خطط» → إضافة (اسم، مبلغ بالدولار، فترة: شهري/فصلي/سنوي).
- **فواتير**: «الرسوم» → «إنشاء فواتير» (اختر خطة وطلابًا وتاريخ استحقاق).
- **تسجيل دفعة**: افتح الفاتورة → «تسجيل دفعة» (مبلغ، تاريخ، طريقة: نقد/تحويل، ملاحظات).
- **إعفاء**: «إعفاء الفاتورة» (للحالات الخاصة).
- **تذكير**: يُرسل إشعار تلقائي لولي الأمر عند إنشاء فاتورة.

> المبالغ بالدولار. تُعرض قيمتها بالليرة (1$ = 90,000 ل.ل افتراضيًا) ويمكن تعديل سعر الصرف من «الإعدادات».

## 8. الشهادات

1. من تفاصيل الحلقة أو «الشهادات» → «إصدار شهادة».
2. اختر طالبًا، نوع الشهادة، عنوان، تاريخ الإصدار.
3. «إصدار» → يُنشأ رقم تسلسلي. يمكن طباعتها من `/certificates/[id]`.
4. التحقق العام (بدون تسجيل دخول): `/verify/[serial]`.

## 9. التقارير

1. «التقارير» → اختر فترة (من/إلى) وحلقة (اختياري).
2. تبويبات: حضور، حفظ، رسوم، معلمون.
3. «تصدير CSV» لفتح في Excel. «طباعة» لقسم واحد.
4. تقرير شخصي للطالب: من تقرير الحضور → «تقرير» بجانب اسمه.

## 10. الإعدادات

- «الإعدادات» → تعديل: اسم المدرسة، phone، عنوان، hours (أيام/وقت)، نص «عن المدرسة»، العملة وسعر الصرف.
- «نسخة احتياطية» → تحميل ملف قاعدة البيانات.
- «تفعيل واتساب» / «اختبار إرسال» (إن كانت مُعدّة).

## 11. سجل التدقيق

- «سجل التدقيق» → بحث/فلترة (إجراء/كيان/تاريخ). يُسجّل كل عملية (دخول، إنشاء، تعديل، حذف، أرشفة، استعادة).

## 12. حالة الإطلاق

- «حالة الإطلاق» → فحص تلقائي: بيانات المدرسة، البريد، حسابات تجريبية، نسخة احتياطية.
- عالج كل ⚠️ قبل الإطلاق (راجع docs/LAUNCH-CHECKLIST.md).

## 13. حذف/أرشفة طالب

- «أرشفة» (وليس حذف) → الطالب يُخفى من القوائم but يبقى في السجلات التاريخية.
- «استعادة» لإعادته إلى «نشط».

## 14. النسخ الاحتياطي (يدوي)

- «الإعدادات» → «نسخة احتياطية» → حفظ الملف. أو من الخادم: `sh scripts/backup.sh`.
