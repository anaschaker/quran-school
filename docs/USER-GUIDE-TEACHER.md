# دليل المعلم — مدرسة القرآن الكريم

## 1. تسجيل الدخول

1. افتح الموقع → «تسجيل الدخول».
2. أدخل بريدك (teacher1@… ) وكلمة المرور.
3. ستنتقل إلى «لوحة المعلم» التي تعرض حلقاتك.

## 2. تسجيل الحضور

1. «لوحة المعلم» → افتح حلقة.
2. «تسجيل الحضور» (أو من القائمة).
3. اختر التاريخ.
4. لكل طالب: حاضر / غائب / متأخر / بعذر.
5. «حفظ» (دفعة واحدة).

> الغياب يُشعر ولي الأمر تلقائيًا (إن كانت الإشعارات مُفعّلة).

## 3. تسجيل التسميع

1. من تفاصيل الحلقة → بجانب الطالب «تسميع».
2. اختر النوع: حفظ / مراجعة / تلاوة.
3. سورة، من آية، إلى آية (يتحقق النظام من عدد آيات السورة).
4. التقدير (1-10) وملاحظات.
5. «حفظ». يُحدّث تقدم الطالب.

## 4. إنشاء اختبار

1. من تفاصيل الحلقة → «إنشاء اختبار».
2. عنوان الاختبار، التاريخ.
3. أدخل درجة كل طالب (اترك فارغًا للغائب).
4. «حفظ». تُعرض الإحصاءات (متوسط/أعلى/أقل) في صفحة الحلقة.

## 5. خطة الحفظ (هدف)

1. من تفاصيل الحلقة → بجانب الطالب «خطة الحفظ».
2. حدد نطاق السور/الآيات (من/إلى) وتواريخ البدء والهدف.
3. «حفظ». تُعرض خطة الطالب مع شريط تقدم ووتيرة (متقدم/على المسار/متأخر).
4. «إلغاء الهدف» عند الحاجة.

## 6. شهادات

- «الشهادات» (في لوحة المعلم) → إصدار شهادة لطالب من حلقاتك.

## 7. المراسلة

- «الرسائل» → «محادثة جديدة» → اختر مستلمًا (معلم/مدير/ولي أمر طالبك).
- اكتب رسالة (≤1000 حرف) → «إرسال».
- التحديث تلقائي كل 15 ثانية.

## 8. الإعلانات

- «الإعلانات» (إن كانت متاحة) → عرض الإعلانات الموجهة لك ولطلابك.

## نصائح

- لا تشارك كلمة مرورك.
- غيّر كلمة المرور المؤقتة عند أول دخول.
- تواصل مع الإدارة عند مشكلة في الحساب.
